JobKit job search capabilities

Current slice: v0.6.0. JobKit now covers public-board discovery, hidden-market targeting, inbox triage, relationship routing, apply packages, tracker outcomes, and calibrated ranking from observed results.

Calibration gap closed

Search stack

Public boards

  • Greenhouse, Lever, and Ashby APIs
  • Partial-result warnings by default
  • --strict fail-fast mode

Opportunity ranking

  • Keyword fit, compensation, freshness
  • Saturation risk and persona fit
  • --sort opportunity|comp|freshness

Calibration

  • jobkit calibrate report
  • jobkit calibrate apply
  • Active weights in ~/.jobkit/calibration.yaml

Workflow

Discover find, saved searches, target packs, and company ATS boards produce scored jobs.
Queue --inbox saves deduped jobs with fit score, source, compensation, and opportunity components.
Act apply-plan, outreach drafts, form-fill packets, and contacts support human-reviewed applications.
Learn Tracker outcomes calibrate opportunity weights so future searches rank closer to what actually converts.

Command map

Need Command State

Residual risk

Data quality matters. Calibration is now implemented, but it only gets useful after the inbox and tracker contain enough real positive and negative outcomes for the active persona.
