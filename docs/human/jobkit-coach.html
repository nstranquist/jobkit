JobKit Coach operator guide

Companion to the JobKit user guide. JobKit Coach creates role-specific interview drills from reviewed public evidence. It stores all practice state on this computer.

Workflow

1. Import evidence

Import a public source bundle. The import rejects private paths and broken evidence links.

2. Build a deck

Build a deck for one job description. Choose a drill mode and a time limit.

3. Practice and review

Use jobkit coach study to learn the six OSS pins in order. Use a deck to practice one job description. JobKit records the score and the next step.

Commands

# nicos-tools users: verify the resume facts and public proof, then import.
ndev catalog portfolio coach sync

# Standalone JobKit users can import a reviewed bundle directly.
jobkit coach study
jobkit coach study --module docs-puller --answer "local-first sqlite fts5 bm25 eval hit@1"
jobkit coach source import public-bundle.json
jobkit coach deck --job posting.txt --mode mixed --minutes 20
jobkit coach run latest
jobkit coach stats
jobkit coach serve

Open http://127.0.0.1:7331 after the server starts. The server rejects non-loopback addresses.

Scoring contract

AreaWeightWhat JobKit checks
Structure25The answer contains the required answer structure.
Decisions and tradeoffs25The answer covers expected concepts, alternatives, constraints, and risks.
Role relevance20The answer uses skills from the target job description.
Evidence safety20Every quantified claim matches an imported claim.
Concision10The answer length fits the allotted response time.

CAUTION: An unsupported quantified claim caps the answer below 60. JobKit schedules that answer for review in one day.

AI and voice adapters

Deterministic scoring remains authoritative. A model can add advisory feedback after scoring.

JobKit executes configured argument arrays directly. It does not use a shell.

A transcriber can receive a private temporary WAV file. JobKit deletes that file after transcription.

The ndev bridge configures local Ollama and optional hosted providers. A provider name that ends in -hosted sends the practice request and answer text to that provider. Select it only when you approve that boundary.

Privacy boundary

Source bundles must use scope: public. Do not import private catalog data or local evidence paths.

Answers and session telemetry stay under ~/.jobkit/coach. Hosted provider use requires an explicit provider name.

Build a new deck after the source bundle changes. JobKit rejects stale decks and malformed answer sets.
