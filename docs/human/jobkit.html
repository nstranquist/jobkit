JobKit user guide

JobKit is a local job-search toolkit. It finds roles on public company boards, scores fit against a trusted profile, prepares application packages, and tracks the funnel. It does not submit applications. It does not invent experience.

01Contract

JobKit does

Keep candidate state on this computer. Score fit from a reviewed profile. Prepare packages a human can send. Record history in append-only ledgers.

JobKit does not

Submit a form. Send outreach. Scrape LinkedIn, Wellfound, Google Jobs, or Indeed. Invent a metric, skill, or claim. Publish ~/.jobkit.

Warning A human must review every package before any send. JobKit never clicks submit. If ~/.jobkit/claims.yaml exists, generated numbers must match that allowlist.
Search boundary jobkit find and saved searches query public Greenhouse, Lever, and Ashby APIs only. Use other boards by hand. Apply on the company URL. Tag the lane with --source.

02Install

Build the binary from the JobKit repository. Then put it on your PATH.

cd ~/tools/jobkit
make install
jobkit version

The default state directory is ~/.jobkit. Set JOBKIT_HOME to use a different directory.

Proof jobkit version prints 0.10.1. make demo runs the full walkthrough in an isolated home and never reads your real state.

03First hour

ProfileCreate or bootstrap the YAML profile. Validate it before any search.
ConstraintsWrite hard limits in the eligibility file. Fit and eligibility stay separate.
DiscoverRun a saved search or find. Queue matches into the inbox.
PrepareBuild an apply-plan. Review the package. Then submit by hand.
jobkit profile bootstrap --source ~/Downloads/resume.pdf --out auto
jobkit profile validate

jobkit eligibility init --home "St. Louis, MO" \
  --countries "United States,USA,US" --languages English \
  --years 7 --relocation-open

jobkit search init
jobkit find backend go --targets ai-infra --remote \
  --sort opportunity --persona backend-platform \
  --eligibility actionable --inbox

jobkit inbox list
jobkit apply-plan <inbox-id> --tone warm

If you already have a reviewed profile, skip bootstrap and run jobkit profile validate.

04Weekly loop

The default slate is 10 roles: 5 platform, 3 full-stack, 1 adoption, 1 stretch. One employer can appear at most twice.

WhenCommandAction
Monday jobkit search digest --inbox --out auto Review the digest. Then run jobkit inbox slate --out auto.
Daily jobkit apply-plan <id> Review the package. Submit on the company site. Track the send.
Daily jobkit inbox outreach <id> Edit the draft. Send the note yourself. Record the contact.
Friday jobkit --json track stats Compare conversion by lane and source. 
jobkit inbox slate --out auto
jobkit inbox stale --days 14
jobkit track followups --days 7
jobkit calibrate report --persona backend-platform
Caution Do not add a SpaceX-family saved search to the default digest. That board is large and mostly on-site. If relocation is open, run a separate find against the spacex-family target. 
jobkit find "software engineer" --targets spacex-family \
  --sort opportunity --persona backend-platform --eligibility actionable

05Surfaces

profile

Trusted profile

One YAML file. Skills, bullets, and aliases feed every later command.

eligibility

Hard constraints

Country, language, years, role family, travel, management, and sales stay out of fit score.

find / search

Public boards

Greenhouse, Lever, and Ashby. Opportunity rank uses pay, freshness, saturation, and persona.

company / contact

Hidden market

Target companies, dated hiring signals, and a referral ledger.

inbox

Pre-application queue

Deduped jobs with source, fit, eligibility, and last-seen provenance.

match / apply

Packages

Resume, letter, prep, and receipts. No submit. Claims fail closed when the allowlist exists.

track

Funnel ledger

Append-only events. Stats by lane, source, and resume version.

coach

Interview drills

Public evidence only. Deterministic score. Optional model feedback is advisory.

06Search

Name a board as provider:slug. Groups start with @. Target packs start with #.

ProviderSpecTypical URL
Greenhousegreenhouse:stripejob-boards.greenhouse.io/stripe
Ashbyashby:OpenAIjobs.ashbyhq.com/OpenAI
Leverlever:includedhealthjobs.lever.co/includedhealth
 
jobkit find "platform engineer" --boards greenhouse:cloudflare,ashby:Temporal
jobkit search run platform-engineering-weekly --inbox
jobkit search digest --inbox --out auto

One stale board prints a warning and the rest of the results still return. Pass --strict to fail on the first board error.

Sort with --sort opportunity|comp|freshness. Filter pay with --min-comp N. Bias rank with --persona values agent-infra, ai-product, devtools, or backend-platform.

After jobkit calibrate apply writes ~/.jobkit/calibration.yaml, search uses those weights automatically.

Source tags

Any source string is valid. Use these tokens so Friday stats compare lanes.

ats google-jobs linkedin wellfound yc trueup hn referral inbound community stl cold

Keep any longer operator source list outside this repository. The tokens above are the public vocabulary.

07Eligibility

Eligibility is not fit. A high keyword score cannot promote an ineligible role into an apply package.

ClassMeaningDefault search
eligibleThe role meets every hard constraint.Included in actionable
reviewA constraint is unknown. Example: relocation needed.Included in actionable
ineligibleA hard constraint fails.Excluded

apply and apply-plan fail closed on an ineligible role. A human can pass --override-eligibility. JobKit records that override on the tracker and in the package receipt.

08Inbox

The inbox is the pre-application queue. IDs are stable. A repeat save of the same posting does not create a second row.

jobkit inbox list
jobkit inbox show <id>
jobkit inbox set <id> --status shortlisted
jobkit inbox note <id> "hiring manager is ex-Bayer"
jobkit inbox form <id> --format js --out auto
jobkit inbox outreach <id> --channel linkedin --out auto

inbox form --format js emits a DevTools snippet. The snippet fills standard Greenhouse, Lever, and label-matched fields. It never touches uploads, EEO fields, or submit.

Inbox status moves through new, shortlisted, planned, and applied. A repeated apply-plan on an active item reuses the tracker record. It does not move an applied, skipped, or archived item back to planned.

09Apply packages

A job description argument can be a file, a supported posting URL, stdin (-), or an inbox id.

jobkit match https://job-boards.greenhouse.io/acme/jobs/123
jobkit apply-plan <inbox-id> --tone warm
jobkit apply https://job-boards.greenhouse.io/acme/jobs/123 --tone warm

Output lands in ~/.jobkit/out/<id>/. A typical package contains the tailored resume, letter, prep sheet, match receipt, eligibility receipt, and the raw job text.

Resume formats are md, txt, html, and pdf. PDF export uses headless Chrome. Set JOBKIT_CHROME_BIN if detection fails.

Letter tones are professional, warm, and direct. The letter names the top required gap instead of hiding it.

Claims gate Run jobkit claims init from the profile. Then run jobkit claims check. Resume, letter, apply, and apply-plan fail if a number is not on the allowlist. Contact details and calendar years are exempt.

10Tracker

The tracker is an append-only JSONL ledger. State is a replay. Events are never rewritten.

Status order: discovered, interested, applied, screening, interview, offer, accepted. Terminal status values are rejected, withdrawn, and ghosted.

jobkit track set <id> --status applied \
  --lane platform --source ats --resume-version v1.9.0
jobkit --json track stats
jobkit track followups --days 7
jobkit track remind --format ics --out auto

Pass a nicos-resume package receipt with --resume-manifest. JobKit rejects candidate or history manifests, failed gates, and a file whose digest does not match the receipt.

track stats groups conversion by tag. lane and source are the useful Friday cohorts.

11Coach

Coach has two loops. jobkit coach study teaches hiring-pin OSS courses plus extra honest OSS modules and scores practice against expected concepts. jobkit coach source|deck|run still builds JD-tied interview drills from a reviewed public evidence bundle. Private catalog paths are rejected on import.

jobkit coach study
jobkit coach study --module docs-puller --answer "local-first sqlite fts5 bm25 eval hit@1"

# nicos-tools path: check resume facts, then import.
ndev catalog portfolio coach sync

# Standalone path:
jobkit coach source import examples/coach-source.json
jobkit coach deck --job posting.txt --mode mixed --minutes 20
jobkit coach run latest
jobkit coach stats
jobkit coach serve

Open the printed loopback URL after coach serve. The server binds only to loopback addresses. It uses an ephemeral token and a protected cookie.

AreaWeightWhat JobKit checks
Structure25The answer has the required structure.
Decisions and tradeoffs25Concepts, alternatives, constraints, and risks.
Role relevance20Skills from the target job description.
Evidence safety20Every quantified claim matches an imported claim.
Concision10Length fits the allotted response time.
Caution An unsupported quantified claim caps the score below 60. JobKit schedules that answer for review in one day. Model feedback cannot replace the deterministic score. A provider name that ends in -hosted sends the practice request and answer text to that provider.

12State

All personal state lives under JOBKIT_HOME. The default is ~/.jobkit. Do not commit that directory.

FileKindPurpose
profile.yamlYAMLTrusted skills and bullets
eligibility.yamlYAMLHard constraints
searches.yamlYAMLBoard groups, targets, saved queries
companies.yamlYAMLTarget companies and ATS slugs
claims.yamlYAMLVerified number allowlist
calibration.yamlYAMLLearned opportunity weights
inbox.jsonlJSONLPre-application queue
applications.jsonlJSONLApplication events
contacts.jsonlJSONLPeople and referral state
telemetry.jsonlJSONLCommand identity, duration, typed error
out/dirGenerated packages
coach/dirPublic source, decks, private answers

YAML files reject unknown fields and trailing documents. JSONL writers take a file lock before each append. New files are private: Unix mode 0600, Windows ACL for the current user.

Telemetry schema v2 stores an allowlisted command id, success, duration, and typed error class. It does not store arguments, paths, output, or raw errors. Set JOBKIT_TELEMETRY=off to disable it.

jobkit doctor telemetry
jobkit doctor telemetry --migrate

Run --migrate only after you review the counts. Migration removes legacy arguments and raw errors.

14Agent contract

Every verb accepts --json. Success is {ok, data}. Failure is {ok:false, error:{code, message, hint}}.

ExitMeaning
0Success
1Runtime error
2INVALID_ARGS
3NOT_FOUND

Flags can appear anywhere. Forms are --k v and --k=v.

An agent can prepare a package, a form-fill snippet, and an outreach draft. An agent must not submit a form or send a message without a human review.

16Fix problems

SymptomLikely causeFix
Search returns nothing Wrong board slug, or remote: true dropped on-site roles Run jobkit search show NAME. Confirm the slug on the company careers page.
Board warning on stderr One ATS in the group failed Keep the partial result, or pass --strict to fail the run.
Apply-plan refuses the role Eligibility is ineligible Read the reasons. Change the policy, or record --override-eligibility.
Resume or letter fails claims A number is not on the allowlist Run jobkit claims check. Add a verified claim, or remove the number.
PDF export fails Chrome is not on PATH Set JOBKIT_CHROME_BIN to the browser binary.
Coach rejects the deck The imported source changed Import the new bundle. Then build a new deck.
Digest is huge and on-site A relocation board is in the default search set Remove that saved search. Run an explicit find --targets instead.
