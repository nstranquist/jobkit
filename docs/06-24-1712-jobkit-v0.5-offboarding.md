## Review fix

During self-review, `company note` had a real CLI parsing bug: unquoted multi-word company names could create the wrong company entry. Example: `jobkit company note Acme AI "strong fit"` could note `Acme` instead of existing `Acme AI`.

Fixed behavior:

- resolve the longest existing company-name prefix
- write to the canonical matched company name
- reject ambiguous unknown multi-word notes with an `INVALID_ARGS` hint recommending `--note`

Regression tests were added in `cmd/jobkit/main_test.go`.

## Remaining non-blocking risk

Opportunity ranking is heuristic. The code is structurally tested, but score weights are not calibrated against a real job-search outcome dataset. The next meaningful improvement is ranking calibration from observed outcomes, not more command-surface work.
