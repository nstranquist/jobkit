# JobKit v0.6 calibration offboarding

Date: 2026-06-24

## Shipped

- Version bumped to `jobkit 0.6.0`.
- Opportunity ranking now has a calibration layer:
  - `jobkit calibrate path`
  - `jobkit calibrate show`
  - `jobkit calibrate report [--persona NAME]`
  - `jobkit calibrate apply [--persona NAME] [--min-samples N] [--force]`
  - state file: `~/.jobkit/calibration.yaml`
- `find`, `search run`, and `search digest` automatically use active
  calibration weights when `calibration.yaml` exists.
- Missing calibration falls back to default weights; malformed calibration fails
  visibly with a hint to fix or remove the file.
- Saved inbox jobs now retain compensation and opportunity score components, so
  calibration can learn from the discovery-time ranking signals.
- Calibration joins inbox items to application tracker outcomes by normalized
  URL first, then company/role fallback. Tracker status wins over inbox status.

## Remaining risk

No blocking implementation gap remains from the v0.5 review. Calibration is now
implemented and covered, but the quality of suggested weights depends on
collecting enough real positive and negative outcomes for the active persona.
