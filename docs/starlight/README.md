# JobKit docs (Starlight comparison)

Astro Starlight rendering of the JobKit v0.9.0 operator guide. The custom
single-file HTML sibling is [`../human/jobkit.html`](../human/jobkit.html).

```sh
cd docs/starlight
pnpm install
pnpm dev     # http://127.0.0.1:4322
```

This folder is a documentation comparison lab. It is not the JobKit runtime.
