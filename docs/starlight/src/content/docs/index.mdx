## What this site is

This is the **Astro Starlight** rendering of the same JobKit v0.9.0 operator guide. The custom single-file HTML lives at `docs/human/jobkit.html`. Open both and compare search, sidebar, dark mode, and density.

<CardGrid stagger>
	<Card title="Does" icon="approve-check">
		Keeps state on this computer. Scores fit from a reviewed profile. Prepares packages a human can send. Records history in append-only ledgers.
	</Card>
	<Card title="Does not" icon="error">
		Submit a form. Send outreach. Scrape LinkedIn, Wellfound, Google Jobs, or Indeed. Invent a metric, skill, or claim. Publish `~/.jobkit`.
	</Card>
	<Card title="Search boundary" icon="magnifier">
		`jobkit find` queries public Greenhouse, Lever, and Ashby APIs only. Other boards stay operator-side. Tag them with `--source`.
	</Card>
	<Card title="Human review" icon="seti:lock">
		A human must review every package before any send. If `~/.jobkit/claims.yaml` exists, generated numbers must match that allowlist.
	</Card>
</CardGrid>
