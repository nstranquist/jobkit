---
title: Environment
description: JOBKIT_* variables.
---

| Variable | Purpose |
|---|---|
| `JOBKIT_HOME` | State directory. Default `~/.jobkit`. |
| `JOBKIT_PROFILE` | Profile path override for a second persona. |
| `JOBKIT_TELEMETRY=off` | Disable per-run telemetry. |
| `JOBKIT_CHROME_BIN` | Chrome or Chromium binary for PDF export. |
| `JOBKIT_GREENHOUSE_BASE` | Test override for the Greenhouse API. |
| `JOBKIT_LEVER_BASE` | Test override for the Lever API. |
| `JOBKIT_ASHBY_BASE` | Test override for the Ashby API. |
